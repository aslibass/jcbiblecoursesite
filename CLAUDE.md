# Claude Code Configuration

## MCP Servers

This project uses the Claude Design MCP to access and manage design projects.

### claude-design
- **URL**: https://api.anthropic.com/v1/design/mcp
- **Description**: Claude Design system for accessing design projects and components
- **Authentication**: Design system authorization (via `/design-login`)

## Usage

Access Claude Design projects using the MCP tools to read design files and resources.
